def search(question, title):
    # Embed the question, as Step 12 embedded a lead

\begin{frame}{Key takeaways}
    \begin{enumerate}
        \item Call a model \textbf{as a function}: one request in, JSON or one tool call out. Your code decides what runs.
        \item \textbf{Valid JSON can still be wrong.} Check it against something you trust.
        \item Datalab \textbf{read} some of its output and its model \textbf{wrote} the rest.
        \item The same request can return a different answer. \textbf{Record} the model, the date, and the response.
        \item A similarity says how much a text changed. \textbf{Read} it to learn why.
    \end{enumerate}
\end{frame}
