\begin{frame}{Key takeaways}
    \begin{enumerate}
        \item Call a model \textbf{as a function}: one request in, JSON in your schema out. No conversation.
        \item \textbf{Valid JSON can still be wrong.} Check it against something you trust: a sum, a second tool, a ground truth.
        \item Document APIs \textbf{read} some things and \textbf{write} others. A chart's description is the model's, not the document's.
        \item The same request can give a different answer. \textbf{Record} the model, the date, and the raw response.
        \item Embeddings find \textbf{topics}, not figures; an answer needs its \textbf{sources}, and null when there are none.
    \end{enumerate}
\end{frame}
