    response = requests.post(
        f"{openrouter_base}/embeddings",

\begin{frame}{Key takeaways}
    \begin{enumerate}
        \item Call a model \textbf{as a function}: one request in, JSON in your schema or one tool call out. Your code decides what runs.
        \item \textbf{Valid JSON can still be wrong.} Check it against something you trust: a sum, a second tool, a ground truth.
        \item Document APIs \textbf{read} some things and \textbf{write} others. A model wrote the chart's description; the document didn't print it.
        \item The same request can give a different answer. \textbf{Record} the model, the date, and the raw response.
        \item Embeddings measure how alike two texts are. \textbf{Read} them to learn why they changed. An answer needs its \textbf{sources}, or null.
    \end{enumerate}
\end{frame}
