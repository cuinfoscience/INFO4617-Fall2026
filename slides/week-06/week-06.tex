\begin{frame}{Common research designs: a 2$\times$2 spectrum}

    Before picking a parsing strategy, place your project on two axes: how many \textbf{sites} you're pulling from, and how \textbf{consistent} their design is page to page.
    \bigskip
    \begin{itemize}\small
        \item \textbf{Single site, consistent design.} Fifty-two weekly Box Office Mojo pages --- same template every time.
        \item \textbf{Single site, inconsistent design.} One oscars.org ceremony page but changes across years and nominees.
        \item \textbf{Multiple sites, consistent design.} English and French Wikipedia infoboxes --- same platform, different specifics.
        \item \textbf{Multiple sites, inconsistent design.} Different movie sites will have unrelated structures.
    \end{itemize}
\end{frame}

\begin{frame}[fragile]{Step 8: every row, given}
    \begin{columns}[T]
        \begin{column}{0.37\textwidth}
            Your last cell, for every row, as a function. It's given.

            \medskip
            \texttt{find()} gives \texttt{None} when a row has no label or no value. What does the \texttt{if} do with that row?
        \end{column}
        \begin{column}{0.6\textwidth}
\begin{lstlisting}
def read_infobox(table):
    facts = {}
    for row in table.find_all("tr"):
        label = row.find("th")
        value = row.find("td")
        # Keep a row only when it has both
        if label and value:
            key = label.get_text(strip=True)
            facts[key] = value.get_text(" ", strip=True)
    return facts
\end{lstlisting}
        \end{column}
    \end{columns}

\begin{frame}{Key takeaways}
    \begin{enumerate}
        \item Scraping is a pipeline: \textbf{retrieve $\rightarrow$ inspect $\rightarrow$ anchor $\rightarrow$ extract $\rightarrow$ DataFrame}.
        \item Tables, decoys, infoboxes, and cards are different shapes of the same problem --- finding a reliable anchor.
        \item Abstract into functions, rate-limit in the loop, and code defensively.
        \item Pages change: the durable skill is \textbf{inspect, hypothesize, verify} not memorized div class names.
    \end{enumerate}
    \bigskip
