% ------------------------------------------------------------------ step 1
\step{Ask for the page, and say who you are}
\begin{code}
import requests
from bs4 import BeautifulSoup
import pandas as pd

url = "https://www.oscars.org/oscars/ceremonies/2026"
headers = {"User-Agent": "WebDataScience/1.0 (you@colorado.edu)"}
response = requests.get(url, headers=headers)
response.status_code
\end{code}
\begin{out}
200
\end{out}
Put your own email address in place of \texttt{you@colorado.edu}. The
\texttt{User-Agent} header tells the server who is asking; without it,
oscars.org answers \texttt{403} (Forbidden). \texttt{200} means that the
server sent the page.

% ------------------------------------------------------------------ step 2
\step{Parse the HTML}
\begin{code}
soup = BeautifulSoup(response.text, "html.parser")
soup.title.get_text()
\end{code}
\begin{out}
'The 98th Academy Awards | 2026'
\end{out}
\texttt{soup} holds the page as a tree of tags that you can search. The
title tells you that you have the ceremony page, not an error page.

% ------------------------------------------------------------------ step 3
\step{Find one card in DevTools}
Open the page in Chrome, right-click the name MICHAEL B. JORDAN, and
select \textbf{Inspect}. The Elements panel opens with the \texttt{<div>}
for that name selected (Figure~2). An indented line sits inside the
nearest less-indented line above it. Read up from the selected line to
find the containers around the name, and down to find the parts next to
it. Click a triangle to open a collapsed line; Figure~2 has the film's
\texttt{<div class="field">} open.

Look at the \texttt{class} attribute on each line. It holds several class
names, separated by spaces. In Figure~2, the line at \mk{5} has three names:
\cls{field}, \cls{field--name-field-honoree-type}, and \cls{winner}.
oscars.org is built with Drupal, a content management system that makes
most of these names from the names that the site gave its fields:
\cls{field--name-} plus a field name, and \cls{paragraph--type--} plus a
type of block. These names tell you what a div holds. Names such as
\cls{field} and \cls{field__item} tell you only that the div is a box.

% ------------------------------------------------------------------ step 4
\step{Match one class name, then count the matches}
\begin{code}
name_tag = soup.find("div", class_="field--name-field-award-category-oscars")
name_tag["class"]
\end{code}
\begin{out}
['field',
 'field--name-field-award-category-oscars',
 'field--type-entity-reference',
 'field--label-hidden',
 'field__item']
\end{out}
BeautifulSoup keeps the \texttt{class} attribute as a list of names.
\texttt{class\_="..."} matches a tag when your name is any one item in
that list, so you give only the one name that you need. (The underscore
is necessary because \texttt{class} is a reserved word in Python.) Now
count what each name matches on the whole page. The last item is the
whole attribute from the line at \mk{5}, copied from DevTools:
\begin{code}
for name in ["field", "field__item", "paragraph",
             "field--name-field-award-categories",
             "paragraph--type--award-category",
             "field--name-field-award-category-oscars",
             "paragraph--type--award-honoree",
             "field--name-field-honoree-type",
             "field--name-field-award-entities",
             "field--name-field-award-film",
             "field field--name-field-honoree-type winner"]:
    print(len(soup.find_all("div", class_=name)), name)
\end{code}

The general names match hundreds of divs: cards, honorees, and the rest of

against the page. The page shows 24 category headings, so 24 cards \mk{2}
is correct. There are 125 honorees \mk{4} and 125 of each field
\mk{5}\,\mk{6}\,\mk{7}, so each honoree has one of each. The whole
attribute finds only the 25 winners: a string with spaces must match the
attribute exactly, names and order. Select the one name that describes the
content, then check its count.

% ------------------------------------------------------------------ step 5
\step{Go to the area \protect\mk{1}, then collect the cards \protect\mk{2}}
\begin{code}
area = soup.find("div", class_="field--name-field-award-categories")
categories = area.find_all("div", class_="paragraph--type--award-category")
len(categories)
\end{code}
\begin{out}
24
\end{out}
\texttt{find} returns the first match: one tag. \texttt{find\_all} returns
a list of all the matches. You call \texttt{find\_all} on \texttt{area},
not on \texttt{soup}, so it searches only inside the awards area.
\texttt{categories} is a list of the 24 cards, in the order of the page.

% ------------------------------------------------------------------ step 6
\step{Take one card and read its name \protect\mk{3}}
\begin{code}
cat = categories[0]
name_tag = cat.find(class_="field--name-field-award-category-oscars")
name_tag.get_text(strip=True)
\end{code}
\begin{out}
'Actor in a Leading Role'
\end{out}
Build the steps for one card before you build them for 24.
\texttt{cat.find(...)} searches only inside this card. This \texttt{find}
has no \texttt{"div"}, so it matches any tag with the class; every field
on this page is a div, so both forms work. \texttt{get\_text(strip=True)}
gives the text inside the tag, without the spaces and line breaks around
it.

% ------------------------------------------------------------------ step 7
\step{Collect the honorees \protect\mk{4} in that one card}
\begin{code}
honorees = cat.find_all("div", class_="paragraph--type--award-honoree")
len(honorees)
\end{code}
\begin{out}
5
\end{out}
In Step~4, this class name matched 125 divs on the whole page. Searched
from \texttt{cat}, it matches the 5 in this card. Where you start a search
decides what you get back. \texttt{find\_all} also looks at every level
below \texttt{cat}, so you do not step through the two wrapper divs between
the card and its honorees (\cls{field--name-field-award-honorees} and
\cls{field__item} in Figure~2).

% ------------------------------------------------------------------ step 8
\step{Extract the three fields \protect\mk{5}\,\protect\mk{6}\,\protect\mk{7} from one honoree}
\begin{code}
h = honorees[0]
type_tag = h.find(class_="field--name-field-honoree-type")
entity_tag = h.find(class_="field--name-field-award-entities")
film_tag = h.find(class_="field--name-field-award-film")
print(type_tag.get_text(strip=True))
print(entity_tag.get_text(strip=True))
print(film_tag.get_text(strip=True))
\end{code}
\begin{out}
Winner
Michael B. Jordan
Sinners
\end{out}
Each \texttt{find} starts from \texttt{h}, so it finds only the fields of
this honoree. To see what \texttt{strip=True} removes, look at the raw
text:
\begin{code}
entity_tag.text
\end{code}
\begin{out}
'\nMichael B. Jordan\n'
\end{out}
The line breaks come from the HTML around the inner \cls{field__item} div.
The type is also a class name (\cls{winner} or \cls{nominee}), but the
text is what you want in the table.

% ------------------------------------------------------------------ step 9
\step{Make one row for each honoree in the card}
\begin{code}
category_name = name_tag.get_text(strip=True)
rows = []
for h in honorees:
    rows.append({
        "category": category_name,
        "honoree_type": h.find(class_="field--name-field-honoree-type").get_text(strip=True),
        "entity": h.find(class_="field--name-field-award-entities").get_text(strip=True),
        "film": h.find(class_="field--name-field-award-film").get_text(strip=True),
    })
rows[1]
\end{code}
\begin{out}
{'category': 'Actor in a Leading Role',
 'honoree_type': 'Nominees',
 'entity': 'Timothée Chalamet',
 'film': 'Marty Supreme'}
\end{out}
The three \texttt{find} calls from Step~8 go inside the loop, and their
text goes into a dictionary: one dictionary per row, with the keys as
column names. \texttt{rows} now holds 5 rows, and \texttt{rows[1]} is the
second. \texttt{category\_name}, from Step~6, puts the card's name in each
row. The page shows NOMINEES only once, but the HTML has the label in
every nominee block; a script on the page hides the repeats
(\texttt{style="display: none;"} in DevTools). \texttt{requests} does not
run scripts, so each row gets its label.

% ----------------------------------------------------------------- step 10
\step{Put the card loop inside a loop over all 24 cards}
\begin{code}
rows = []
for cat in categories:                                                      # Step 5
    name_tag = cat.find(class_="field--name-field-award-category-oscars")   # Step 6
    if name_tag is None:                                                    # guard
        continue
    category_name = name_tag.get_text(strip=True)                           # Step 6
    for h in cat.find_all("div", class_="paragraph--type--award-honoree"):  # Step 7
        type_tag = h.find(class_="field--name-field-honoree-type")          # Step 8
        entity_tag = h.find(class_="field--name-field-award-entities")      # Step 8
        film_tag = h.find(class_="field--name-field-award-film")            # Step 8
        rows.append({                                                       # Step 9
            "category": category_name,
            "honoree_type": type_tag.get_text(strip=True) if type_tag else None,
            "entity": entity_tag.get_text(strip=True) if entity_tag else None,
            "film": film_tag.get_text(strip=True) if film_tag else None,
        })
len(rows)
\end{code}
\begin{out}
125
\end{out}
Two things are new. First, the outer loop \texttt{for cat in categories:}
runs Steps~6 to~9 once for each card. \texttt{rows = []} moves above it,
so all 24 cards add their rows to one list. Second, guards. \texttt{find}
returns \texttt{None} when nothing matches, and calling
\texttt{.get\_text()} on \texttt{None} raises an \texttt{AttributeError}
that stops the whole loop. \texttt{if name\_tag is None: continue} skips a
card that has no name, and \texttt{... if type\_tag else None} records a
missing field as \texttt{None}. On the 2026 page no guard fires. The
guards keep the loop running if one card is shaped differently.
