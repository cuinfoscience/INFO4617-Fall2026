# Week 6's saved copies (checkpoints)

Made by `lab-06-key.ipynb`'s own code on the run its key note describes (2026-11-11), and read by the lab from this folder's raw address on `main`. Each lets a student go on when a site refused a request, or start a day without the earlier days' kernel.

| File | Made by | What it holds |
|---|---|---|
| `list_page.html` | Step 3 | Wikipedia's article *List of highest-grossing films*, as `/wiki/List_of_highest-grossing_films` returned it. Part 2's setup reads it. |
| `films.csv` | Step 6 | The article's first table (50 films), with the chapter's cleanup (`gross`) and the lab's fix (`gross_fixed`). Part 2's setup reads it. |
| `godfather_en.html`, `godfather_fr.html` | Step 11 | The articles *The Godfather* (English) and *Le Parrain (film)* (French). |
| `godfather_es.html` | Step 11's microsprint | The article *El padrino (película)* (Spanish). |
| `quotes.csv` | Step 14 | The 30 quotes on pages 1–3 of [Quotes to Scrape](https://quotes.toscrape.com/): text, author, tags, number of tags, page. Read it with `keep_default_na=False`, so the quote with no tags keeps an empty `tags` cell. |

The quotes in `quotes.csv` come from Zyte's practice site, which credits them to Goodreads.

**Privacy.** The articles name film professionals in public credits and cast lists; `quotes.csv` names the published authors the site quotes. None of the files holds a username, a user or talk page, an IP address or contact details (checked on 2026-11-11).
