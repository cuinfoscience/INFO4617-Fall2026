# Week 5's saved copies (checkpoints)

Made by `lab-05-key.ipynb`'s own code on the run its key note describes (2026-11-11), and read by the lab from this folder's raw address on `main`. Each lets a student go on when the pageviews API refused them (a 429 from a room that shares one address).

| File | Made by | What it holds |
|---|---|---|
| `pageviews-cu-boulder-2026-01.json` | Step 13 | The pageviews API's answer, as sent, for *University of Colorado Boulder*, all access, all agents, daily, 2026-01-01 to 2026-01-31: one item a day with its `timestamp` and `views`. |
| `pageviews-three-articles-2026-01.csv` | Step 14's microsprint | Daily views for the same month for *University of Colorado Boulder*, *Colorado State University* and *University of Denver*, one column each, indexed by `timestamp`. |

**Privacy.** Both files hold article titles, dates and counts only. Nothing from Monday's or Wednesday's requests is saved: no header, no address, no DNS answer.
